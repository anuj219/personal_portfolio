Hospital Management System
- Developed a robust and automated patient management system with modules for admit, visit, and discharge, bed and visiting badge allocation.

Key Features:
- Database handling for efficient patient and visitor management.
- Email handling and automated PDF generation with key credentials like unique QR codes for visitor authentication ; reduced manual processing time by 40%.


Tech Stack:
- PHP, PHPMyAdmin, JavaScript, jQuery, JSON, AJAX, PHPMailer, PHPQrCod
